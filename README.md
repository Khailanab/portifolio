# Portfólio — Sites & Landing Pages

Site de portfólio estático e responsivo para divulgação de serviços de desenvolvimento web.

## Antes de publicar

No `index.html`, troque:

- `Seu Nome` pelo seu nome profissional;
- `SN` pelas suas iniciais;
- `5500000000000` pelo seu WhatsApp com DDI + DDD;
- `seuemail@exemplo.com` pelo seu e-mail;
- os textos dos projetos pelos seus trabalhos reais quando desejar.

## Arquivos

- `index.html` — página principal
- `styles.css` — estilos
- `script.js` — menu mobile e animações
- `demos/` — quatro sites demonstrativos

## Publicação

Pode ser publicado gratuitamente no GitHub Pages, Netlify ou Vercel. Domínio próprio é opcional.
